# YumiCrushSaga

An offline Paraense Match-3 adventure starring Yumi. The app uses SwiftUI for navigation and interface, SpriteKit for the interactive 8×8 board, and the local YumiEngine/YumiApplication Swift package modules for game rules, sessions and tests.

See Documentation/Architecture.md for module boundaries and Documentation/Running.md for local Xcode instructions.

## Web / PWA

The browser game is a separate JavaScript implementation and does not replace the iOS app. See [Documentation/Web.md](Documentation/Web.md) for setup, tests, installation and GitHub Pages instructions, and [ADR 001](Documentation/ADR/001-web-runtime.md) for the architecture decision.

The mascot illustration is an original SwiftUI vector cartoon based on the inspected private photo reference. The photo and concept art remain in the ignored Design/References directory and are not included in the app or Git.
